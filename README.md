# 🍅 番茄钟 - Pomodoro Timer

一个简洁美观的桌面番茄钟应用，单文件 HTML 实现，无需安装任何依赖，打开即用。

## 功能特性

- **三种计时模式** — 25 分钟专注 / 5 分钟短休 / 15 分钟长休
- **自动循环** — 每 4 个番茄钟后自动进入长休
- **可视化圆环进度** — 倒计时进度一目了然，颜色随模式切换
- **桌面通知** — 阶段结束时浏览器推送通知提醒
- **音效提示** — 使用 Web Audio API 播放完成提示音
- **键盘快捷键** — 空格开始/暂停，数字键切换模式
- **统计记录** — 今日番茄数、总计、专注时长，数据本地持久化
- **零依赖** — 纯 HTML/CSS/JS，无需安装任何运行时或依赖

## 使用方法

1. 下载 `pomodoro-timer.html`
2. 双击在浏览器中打开
3. 点击「开始」启动第一个番茄钟

## 键盘快捷键

| 按键 | 操作 |
|------|------|
| `空格` | 开始 / 暂停 / 继续 |
| `1` | 切换到专注模式 |
| `2` | 切换到短休模式 |
| `3` | 切换到长休模式 |
| `R` | 重置当前计时 |
| `S` | 跳过当前阶段 |

## 浏览器兼容性

支持所有现代浏览器（Chrome、Firefox、Edge、Safari）。
